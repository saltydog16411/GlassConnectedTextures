Glass Connected Textures

Minecraft 1.20.1 / Forge 向け
隣接するガラスの内部枠を非表示にし、一枚の連続した窓のように表示します。

主な特徴

・mods フォルダへJARを入れるだけで動作
・クライアント専用。サーバー導入不要
・既存ワールドに設置済みのガラスにも反映
・MODを外せばバニラ表示へ戻る
・通常ガラス、遮光ガラス、16色の色付きガラス、板ガラス、16色の色付き板ガラスに対応
・色違いの色付きガラス同士も接続表示
・元のガラス表面テクスチャを維持
・単体板ガラスや露出端は元の表現を維持
・追加生成ファイル無し

動作環境

・Minecraft 1.20.1
・Forge 47.4.10以上の47.x系
・Java 17

ForgeのBakedModel / ModelData経路を使用しており、Embeddium / Oculusとの併用を想定しています。

導入方法

1. Minecraft 1.20.1 + Forgeを用意します。
2. GlassConnectedTextures-1.20.1-1.0.0.jar を mods フォルダへ入れます。
3. Minecraftを起動します。

不要になった場合はJARを削除するだけです。ワールドデータは変更しません。

対応ブロック

・ガラス
・遮光ガラス
・16色すべての色付きガラス
・板ガラス
・16色すべての色付き板ガラス

ガラスブロック同士、板ガラス同士で接続判定します。ガラスブロックと板ガラスは別グループです。

軽量化処理

ブロック/チャンクモデルを再構築するときだけ近傍状態を確認します。

・近傍確認は直近6方向のみ
・MutableBlockPosを再利用して一時オブジェクト生成を抑制
・接続状態を整数にパックして再利用
・ModelDataを接続状態ごとに再利用
・接続パターンを事前計算し、描画時の分岐を削減
・QuadのUV・向き解析結果をキャッシュ
・一般的な単一Quad出力をキャッシュ
・起動時は対象となるバニラガラスだけを直接登録
